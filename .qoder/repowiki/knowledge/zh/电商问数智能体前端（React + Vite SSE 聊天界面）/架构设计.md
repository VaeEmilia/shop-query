模块采用典型的 Vite + React 单页应用结构：`src/main.tsx` 作为入口挂载 `<App />`；`src/App.tsx` 是状态中心，维护 `messages`、`draft`、`activeController` 等会话状态，负责发起 `/api/query` 请求、处理 SSE 事件并驱动子组件渲染。通信层集中在 `src/lib/agentApi.ts`，使用原生 `fetch` + `ReadableStream` 手动解析 SSE `data:` 行并通过回调 `onEvent` 上抛；类型契约在 `src/types/agent.ts` 中以 discriminated union (`ProgressEvent | ResultEvent | ErrorEvent`) 定义。UI 按职责拆分为 `components/` 下的无状态/受控组件：`Composer`（输入与发送/停止）、`MessageBubble`（消息气泡，组合 `StepRail` 与 `ResultTable`）、`EmptyState`（空态示例）。样式通过 Tailwind CSS + PostCSS 自定义主题色（ink/moss/tomato/parchment 等），Vite 开发服务器将 `/api` 代理到 `VITE_DEV_PROXY_TARGET`（默认 `http://127.0.0.1:8000`），构建时由 `import.meta.env.VITE_API_BASE_URL` 注入生产 API 地址。依赖方向单向：`App → components → lib/*`，组件不直接访问网络或类型定义以外的模块。
