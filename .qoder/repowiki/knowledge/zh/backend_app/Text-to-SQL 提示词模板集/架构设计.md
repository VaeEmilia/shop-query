该模块以纯文本 `.prompt` 文件形式组织，每个文件对应一个独立的 LLM 调用子任务：`generate_sql.prompt` 负责将自然语言查询转换为单条只读 SQL；`correct_sql.prompt` 基于执行错误对已有 SQL 做最小必要修复；`extend_keywords_for_column_recall.prompt`、`extend_keywords_for_metric_recall.prompt`、`extend_keywords_for_value_recall.prompt` 分别用于从用户问题推断必需字段名、候选指标名和字段取值关键词；`filter_table_info.prompt` 与 `filter_metric_info.prompt` 则对已召回的表/指标候选进行二次筛选。所有模板统一采用 `{table_infos}`、`{metric_infos}`、`{date_info}`、`{db_info}`、`{query}`、`{sql}`、`{error}` 等占位符注入上下文，由上层 Python 代码在调用 LLM 前填充，本模块不依赖任何运行时逻辑，仅作为可被外部程序加载的静态提示资源。
